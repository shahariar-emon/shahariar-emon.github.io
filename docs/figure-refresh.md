# Scientific figure refresh

The five figures supplied in `NEW_Figures.zip` are used as theme illustrations. The membrane/water-channel rendering is the main homepage visual; a small portrait keeps the introduction personal. The existing motto, navigation, research descriptions and publication lists are retained.

| Source | Placement and rationale |
| --- | --- |
| `Home_Page_and_Membrane_Permeabilization.png` | Homepage and membrane permeabilization theme. Its clear water-filled channel directly illustrates the central research question. |
| `Use_for_Molecular_transport_model.jpg` | Transport theme. The geometry and narrowing-pore schematic provide an immediately readable overview. |
| `Use_for_Protein_small_molecule_research.png` | Protein–small-molecule theme. The structure and interaction view make this theme visually distinct. |
| `Transport.tif` | “Explore transport simulations” disclosure under transport. The detailed time sequence is available without lengthening the default overview. |
| `Transport_in_COMSOL.jpg` | Same disclosure. The comparative transport maps complement the geometry schematic. |

Captions describe what is visible and use the supplied filename context. No protein identity, ligand identity or association with a particular publication is inferred. These overview illustrations are not labelled as specific published figures. Existing publication-specific detail pages retain their sourced figures.

## Assets

- Responsive WebP images and larger versions for the existing enlargement dialog.
- Full framing, original scientific colours and source transparency are preserved. No scientific labels or content were removed or generated.
- EXIF/XMP metadata is omitted. Width and height reserve space; the homepage figure loads eagerly and other figures load lazily.
- All ten web variants total 1,923,018 bytes, versus 10,414,226 bytes for the five originals (81.5% smaller).

## Validation

Astro production build passed. Browser checks at 1440 px and 390 px confirmed no horizontal overflow or broken images, all five figures and enlargement controls, correct captions, retained colours, transport disclosure behavior and local links. Desktop and mobile screenshots were visually reviewed.
